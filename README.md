# Guoyu Li — Academic Homepage

Static, responsive academic homepage for https://li-guoyu-bupt.github.io/.

## Publish
1. Create the public GitHub repository `Li-Guoyu-BUPT.github.io` under `Li-Guoyu-BUPT`.
2. Upload `index.html`, `style.css` and `.nojekyll` to the repository root.
3. Open Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Customize
- Edit text and email in `index.html`; styles are in `style.css`.
- To add your portrait, replace `<div class="identity" ...>GL</div>` with `<img class="identity" src="assets/portrait.jpg" alt="Guoyu Li">`, upload your image, and add `object-fit:cover` to `.identity`.
- Add a CV link only after uploading a public version of your CV. No CV or photo is included in this package.
- Research descriptions and English award names should be reviewed before publication. No publications or unconfirmed research results are claimed.

No dependencies, external fonts, analytics, or build step required.
